# Benchmark summary

Generated by `python run_pipeline.py report` from the CSV files in this folder.

- Cycle numbers are MEASURED in RTL simulation (Icarus Verilog + cocotb).
- `compute_cycles` = sum over layers of the hardware `cycle_count` counter: the busy
  cycles of one inference with weights already loaded (no host load/read cycles).
- `host_cycles_per_sample` additionally includes writing inputs, the start/done
  handshake and reading outputs, one value per cycle.

## Original design vs new design

Same workload (tiny model layer 0, 8 -> 16) on 4 MACs. Latency is measured the same way
for both: clock edges from asserting `start` until `done` is seen.

| Design | Samples (bit-exact) | start->done cycles | MAC utilization |
|---|---|---|---|
| original (baseline/rtl) | 400 | 49 | 65.31% |
| new generic engine, NUM_MACS=4 | 400 | 35 | 91.43% |

Latency reduction: 28.6% (1.40x fewer cycles).
